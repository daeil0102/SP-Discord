# SP-Discord

해당 프로젝트는 프록시용 서버에서 디스코드 봇 연동하는 프로젝트 입니다

해당 플러그인을 사용하기 위해선 SP-Framework가 필요합니다

해당 프로젝트는 미완성된 프로젝트 입니다 일부 오류가 있을 수 있습니다

추후 단일서버도 지원 예정입니다

## 플러그인 버전

- 플러그인 : spigot 1.12+
    - 1.12.x~1.16.x -all 버전 사용
    - 1.17+ -base
- 벨로시티 : 3.4.0-SNAPSHOT
    - all 버전 사용
